# Examples

This directory contains example configurations and use cases for AWS services.

## Categories

- **Compute** - EC2, Lambda, ECS examples
- **Storage** - S3, EBS, EFS examples
- **Database** - RDS, DynamoDB, ElastiCache examples
- **Networking** - VPC, Route53, CloudFront examples
- **Security** - IAM, KMS, Secrets Manager examples
- **Serverless** - Lambda, API Gateway, Step Functions examples

## Usage

Each example includes:
- README with explanation
- Required configuration files
- Usage instructions
- Expected outcomes

## Contributing

When adding examples:
1. Create a dedicated directory
2. Include comprehensive README
3. Add comments to configuration files
4. Test before committing
5. Document costs and cleanup procedures
